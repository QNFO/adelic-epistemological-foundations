## Quick Start

This project synthesizes 16 preparatory Obsidian notes (July 20–29, 2026) into a coherent epistemological and pedagogical framework for the QNFO Adelic Physics Program.

**The core scientific claims are already published** across 56 QNFO papers. This project provides the **communications infrastructure**: a single, accessible document that explains the program from foundations to implications.

## Quick Start

This project synthesizes 16 preparatory Obsidian notes and 56 published QNFO papers into a **synthesis and survey** of the QNFO Adelic Physics Program.

**DOI:** 10.5281/zenodo.21685479  
**Paper:** https://papers.qnfo.org/papers/adelic-epistemological-foundations  
**Source:** https://github.com/QNFO/adelic-epistemological-foundations

## What This Paper Is

A single entry point to the adelic programme's conceptual foundations:
- **Sections 3-8:** Survey existing QNFO papers with "Further Reading" pointers to underlying technical papers
- **Sections 2, 9, 10:** Novel epistemological framing, domain translation analysis, and observer-centered epistemology
- **Section 1.1:** Explicit "what this paper is/is not" scope disclosure
